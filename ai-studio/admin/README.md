# 后台内容维护页面 · 界面原型

入口：`/admin/`。前台顶部的“上传内容”直达新建案例；资源中心的“收录资源”直达新建技能/MCP。

本阶段不接数据库、真实上传接口或用户登录。页面使用虚拟内容；草稿、状态和历史记录仅保存在当前浏览器 localStorage。选择的本地附件只在当前页面会话内预览，刷新后需重新选择。点击发布不会修改公网案例集。

## 可评审的流程
- 案例、经验文章、Skills/MCP 的列表、搜索与状态筛选。
- 案例：基础信息、发布人、输入提示词、制作步骤、关联资源、封面与附件、Token/时间估算。
- 资源：来源、作者、版本、安装步骤、调用方式、验证说明、MCP JSON。
- 文章：主题、摘要、发布人、阅读时间与正文。
- 保存草稿、预览、模拟发布、下架、历史恢复、未保存提醒。
- 附件用途选择、文件说明、预览、从附件库选择与引用删除保护。

## 代码位置
`admin/index.html` 页面壳；`admin/admin.css` 复用既有视觉系统；`admin/admin.js` 页面与编辑流程；`admin/demo-data.js` 模拟数据提供层。

后续接入真实服务时替换 `STUDIO_ADMIN_PROVIDER`，保留现有编辑页面与数据结构。用户身份和角色由统一登录模块提供，不在此原型中新增账号体系。
